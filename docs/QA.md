# Приёмочная проверка

Автоматические команды: `npm run typecheck`, `npm test`, `npm run build`, `npm audit`.

Ручная проверка в настольном и мобильном браузере:

1. Запустить `npm run dev`, открыть `http://127.0.0.1:5173`.
2. Проверить первичную регистрацию, затем выход и вход администратора.
3. Переключить русский, английский и туркменский; проверить названия, формы, статусы, ошибки и формат дат.
4. Создать объект и клиента с совпадающими типом, валютой и периодом аренды. Проверить сохранение после перезагрузки.
5. Открыть подбор клиента, сравнить результаты с изменением бюджета, района, комнат и площади.
6. Создать сделку и показ. Проверить отказ при пересекающемся показе, попытке удаления связанного объекта и несовместимых параметрах сделки.
7. Открыть одну запись в двух вкладках. Изменить в первой и попытаться сохранить устаревшую во второй: должен появиться конфликт, без потери первой правки.
8. Добавить сотрудника-агента, проверить его доступ. Отключить его администратором, убедиться, что прежняя сессия больше не работает.
9. Проверить журнал действий и смену пароля. Предыдущие сессии должны завершиться.
10. Создать больше 20 записей и проверить пагинацию списков, поиск, фильтры и выбор связанных записей за пределами первой страницы.
11. Проверить клавиатурную навигацию, фокус в диалогах, Escape, ошибки обязательных полей и горизонтальную прокрутку таблиц на телефоне.
12. Выполнить `npm run build`, запустить `npm start`, повторить основные сценарии на порту 3000. Проверить прямую загрузку маршрутов `/properties` и `/clients`.
13. Проверить Swagger UI `/docs/`, спецификацию `/docs/json` и ошибки API.

В текущей среде автоматические тесты и сборка проверяются отдельно; визуальная браузерная проверка не выполнена из-за недоступности службы управления браузером. Docker и GitHub Actions требуют выполнения в соответствующей среде.
